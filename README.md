# 🕹️ Kyne Shared Server Hosting
##🔍 Scope: Small-scale servers with trusted friends.
This project allows for game server files to be stored online(in a github repo) and thereby be hosted by any of its players, at any time.
Recommended for those with decent computers and unable to host a server 24/7 via server providers.
##⚠️ Server files are accessible to ALL players hosting the server, encryption will be added in a future update,
