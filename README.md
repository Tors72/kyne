# 🕹️ Kyne Shared Server Hosting

#### 🔍 Scope: Small-scale servers with trusted friends.
This project allows for game server files(e.g Minecraft) to be stored online(in a github repo) and thereby be hosted by any of its players, at any time.
Recommended for those with decent computers and unable to host a server 24/7 via server providers.
##### ⚠️ Server files are accessible to ALL players hosting the server.

## 📝 Requirements:
 - A decent computer (depends on how heavy the server is to run)
 - Github repository to store server files
 - LogMeIn Hamachi (Optional, if port-forwarding is not an option)
